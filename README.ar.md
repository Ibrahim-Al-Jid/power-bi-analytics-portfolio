## نبذة

أنا **إبراهيم حمدي**، محلل بيانات أعمل على Power BI. يضم هذا المستودع خمسة مشاريع كاملة. كل مشروع فيه ملف اللوحة (`.pbix`) والبيانات ولقطات الشاشة وملف README يشرح الأسئلة التي طُرحت وما تعرضه اللوحة وما تقوله الأرقام.

## المهارات

- تنظيف البيانات وتحويلها في **Power Query (M)**
- نمذجة البيانات (النموذج النجمي والعلاقات)
- مقاييس **DAX** والأعمدة المحسوبة
- تصميم اللوحات والتنقل وسرد القصة بالبيانات
- تحويل الأرقام إلى رؤى وتوصيات

## طريقة الاستخدام

1. ثبّت [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (مجاني، ويعمل على ويندوز).
2. افتح مجلد أي مشروع واقرأ ملف README الخاص به.
3. افتح ملف `.pbix`. إذا طلب Power BI مسار البيانات فوجّهه إلى مجلد البيانات داخل المشروع.
