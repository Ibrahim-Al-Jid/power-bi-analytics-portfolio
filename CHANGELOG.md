## 2026-11-27 overhaul

A full review of the project. Each item below was checked against the code and data in this repository.

### What was wrong

- The five projects were not presented as one portfolio, and most had no proper README.
- The COVID-19 project used the OWID dataset without crediting the source and license.
- A duplicate background image was stored twice (identical to Group 26.png).
- The READMEs carried a contact section the owner did not want public.

### What was fixed

- Five projects consolidated under one portfolio README with a project table.
- Every project README rewritten and checked against the data files; numbers quoted were recomputed.

### What was removed

- Contact sections (English and Arabic).
- The duplicate background image.

### What was added

- English and Arabic README for each of the five projects, with a language switch.
- OWID data source and license credit (English and Arabic).
- About section and social preview image.
- The album-cover image was kept, by the owner's choice.

## Original version

Initial version (2026-01-30): a short README and a banner image, then five Power BI projects uploaded as separate folders with their .pbix files and data.
